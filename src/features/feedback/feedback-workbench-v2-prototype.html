统一 Callback 契约

两个执行器都回写同一种事件，工作台不感知 SDK 差异。

v1
run.started
执行已开始 记录 provider、runId、workflowId。
agent.message
追加时间线回复 摘要、进度和可见日志，不回传内部思维过程。
waiting_human
等待用户补充 Workflow 暂停，Issue 保持打开。
artifact.created
关联交付物 Commit、PR、补丁、截图或测试报告。
run.completed
完成并建议关闭 是否自动关闭由工作台策略决定。
