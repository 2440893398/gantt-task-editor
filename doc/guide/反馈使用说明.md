# 反馈使用说明

面向提交问题反馈的用户，介绍反馈入口在哪里、怎么提交、提交后如何查看处理进度，以及
处理进度页面上各状态的含义。

## 1. 入口位置

甘特图工具栏上有一个「问题反馈」按钮（`#feedback-btn`），点击即可打开反馈弹窗。弹窗
支持：

- 填写反馈内容并提交；
- 录制复现轨迹后自动结束录制并回填草稿（按钮上会出现红点提示正在录制）。

## 2. 提交方式

在反馈弹窗中填写以下信息：

| 字段 | 说明 |
| --- | --- |
| 类型 | 不确定 / Bug / 优化 / 需求 / 其他，用于分流处理 |
| 联系方式（可选） | 邮箱、微信或手机号，便于对方在需要时联系你 |
| 一句话概括 | 必填，简要描述问题，最多 120 字 |
| 问题描述 / 复现步骤 | 说明发生了什么、期望是什么，尽量写清复现步骤 |
| 附件 | 可添加截图、视频，或点击「开始录制」记录一段操作轨迹随反馈一起提交 |

信息填写完整后点击「提交反馈」即可。

## 3. 查看进度

提交成功后，弹窗会给出一个专属链接（「查看处理进度并继续补充」）。这个链接是查看
处理进度、后续补充信息的唯一凭据，请妥善保存：

- 如果需要补充截图、复现步骤或回答处理方的提问，请通过这个链接回到同一条反馈，
  避免重新提交生成重复任务；
- 若链接暂时不可用，请勿重复提交，可稍后联系管理员查询。

## 4. 状态含义

处理进度页面上的状态会随着处理阶段自动更新，含义如下：

| 页面上的状态 | 含义 |
| --- | --- |
| 已受理 | 反馈已创建并进入处理队列，尚未开始自动化处理，或已生成任务等待执行器领取 |
| 处理中 | 处理方正在分析问题或实现修复 |
| 验证中 | 修复方案已产出，正在验证效果，或正在执行集成、部署、冒烟测试 |
| 待确认 | 需要你补充信息、确认某个方案，或由管理员审核后才能继续 |
| 已解决 | 修复方案已完成集成，必要的部署和验证均已通过 |
| 验证未通过 | 已有实现但验证未通过，处理方会重新分析或联系你补充信息 |
| 已关闭 | 管理员已关闭该反馈，不再继续自动处理；如问题仍存在可重新提交或通过原链接回复以重新开启 |

一条反馈从提交到解决，通常会依次经过「已受理 → 处理中 → 验证中 → 已解决」；如果
处理过程中需要你确认信息，会进入「待确认」，你回复后会自动回到相应处理阶段继续。
