# uTools 插件开发实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将 gantt-task-editor 打包为 uTools 插件，实现离线可用

**Architecture:** 通过 Vite 多构建配置 + 环境变量控制，实现单代码库多平台构建。uTools 版本禁用 AI、分享等需要网络的服务，保留核心甘特图功能。

**Tech Stack:** Vite 5, DHTMLX Gantt, Dexie.js, uTools API

**Step 1: 创建 vite.config.utools.js 构建配置**

```javascript
// vite.config.utools.js
import { defineConfig } from 'vite';
import baseConfig from './vite.config.js';

export default defineConfig({
    ...baseConfig,
    build: {
        ...baseConfig.build,
        outDir: 'dist-utools',
        rollupOptions: {
            ...baseConfig.build.rollupOptions,
            // uTools 版本排除 AI 相关代码（减小体积）
            external: ['ai', '@ai-sdk/openai']
        }
    },
    define: {
        // 注入环境变量
        'import.meta.env.VITE_PLATFORM': JSON.stringify('utools'),
        'import.meta.env.VITE_ENABLE_AI': JSON.stringify(false),
        'import.meta.env.VITE_ENABLE_SHARE': JSON.stringify(false),
        'import.meta.env.VITE_ENABLE_HOLIDAY': JSON.stringify(false)

});
```

### Task 2: 创建平台配置文件

**Files:**

**Step 1: 创建平台配置文件**

```javascript
// src/config/platform.js
// 平台配置：根据环境变量决定启用哪些功能

const isUttools = import.meta.env.VITE_PLATFORM === 'utools';

export const platformConfig = {
    // 平台标识
    platform: import.meta.env.VITE_PLATFORM || 'web',

    // 功能开关
    enableAI: !isUttools && import.meta.env.VITE_ENABLE_AI !== 'false',
    enableShare: !isUttools && import.meta.env.VITE_ENABLE_SHARE !== 'false',
    enableHolidayAPI: !isUttools && import.meta.env.VITE_ENABLE_HOLIDAY !== 'false',

    // 数据存储
    storage: 'indexeddb',

    // 窗口配置
    window: {
        width: isUttools ? 1200 : undefined,
        height: isUttools ? 800 : undefined,
    }
};

export default platformConfig;
```

### Task 8: 条件隐藏工具栏按钮

**Files:**
- Modify: `index.html`

**Step 1: 在 index.html 中添加平台检测脚本**

在 `<body>` 开始处添加：

```html
<script>
    // 平台检测
    window.__PLATFORM__ = {
        isUttools: window.utools !== undefined,
        enableAI: true,
        enableShare: true,
        enableHoliday: true
    };

    // 从 URL 参数或环境变量读取
    const params = new URLSearchParams(window.location.search);
    if (params.get('platform') === 'utools') {
        window.__PLATFORM__.isUttools = true;
        window.__PLATFORM__.enableAI = false;
        window.__PLATFORM__.enableShare = false;
        window.__PLATFORM__.enableHoliday = false;
    }
</script>
```

**Step 2: 修改按钮显示逻辑**

找到分享按钮，添加条件类：

```html
<!-- 分享按钮 -->
<button id="share-btn" 
    class="toolbar-icon-btn tooltip tooltip-bottom" 
    data-tip="分享"
    data-i18n-title="share.title" 
    data-i18n-tip="share.title"
    data-platform="web">
```

**Step 3: 添加平台控制 JS**

在 main.js 加载后执行：

```javascript
// 在 src/main.js 或 index.html 中添加
document.addEventListener('DOMContentLoaded', () => {
    const isUttools = window.__PLATFORM__?.isUttools;
    
    if (isUttools) {
        // 隐藏需要网络的功能按钮
        document.querySelectorAll('[data-platform="web"]').forEach(el => {
            el.style.display = 'none';
        });
    }
});
```

**Step 4: Commit**

```bash
git add index.html src/main.js
git commit -m "feat(utools): 添加平台检测和功能按钮条件显示"
```

**Step 2: 创建自动复制脚本（可选）**

创建 `scripts/post-build-utools.js`：

```javascript
// scripts/post-build-utools.js
import fs from 'fs';
import path from 'path';

const distDir = 'dist-utools';
const filesToCopy = ['plugin.json', 'preload.js', 'icon.png'];

filesToCopy.forEach(file => {
    const srcPath = path.join(process.cwd(), file);
    const destPath = path.join(process.cwd(), distDir, file);
    if (fs.existsSync(srcPath)) {
        fs.copyFileSync(srcPath, destPath);
        console.log(`Copied ${file} to ${distDir}/`);
    }
});
```

**Step 3: 更新 package.json**

